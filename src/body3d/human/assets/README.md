# Body model assets

`human-male.bin` and `human-female.bin` are generated by `scripts/bake-body-model.mjs` from the
[MakeHuman](http://www.makehumancommunity.org) base mesh, skeleton, skin weights and morph targets
(repository `makehumancommunity/makehuman`, commit `a8bc2d54ff0ac92e78ff71431b1023eda42bf482`).

The MakeHuman assets were released under **CC0 1.0** in September 2020 (see `LICENSE.ASSETS.md` in that
repository). No MakeHuman code (AGPL) is included; the bake script only reads the data files.

Each file holds, for one sex: the mean body and 48 principal shape components over one symmetric half of
the 13,380-vertex mesh (int8, stature-normalised), the quad topology, a simplified 19-bone skin, a regression
from MakeHuman-style sliders to shape coefficients, and sparse muscle/fat sculpts. To regenerate:

```bash
git clone https://github.com/makehumancommunity/makehuman.git /tmp/makehuman
git -C /tmp/makehuman checkout a8bc2d54ff0ac92e78ff71431b1023eda42bf482
node scripts/bake-body-model.mjs /tmp/makehuman
```
